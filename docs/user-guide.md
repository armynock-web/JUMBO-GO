# JUMBO GO — คู่มือการใช้งานระบบ (User Guide)
**เวอร์ชัน:** 1.4.0  
**แพลตฟอร์ม:** JUMBO GO On-Demand Freight & Logistics Platform  
**มาตรฐาน:** ARM-AI Engineering Standard (ARM-AES)

---

## 1. บทนำและสถาปัตยกรรม 3 บทบาท (Three-Sided Architecture)

JUMBO GO เป็นแพลตฟอร์มบริการขนส่งสินค้า ย้ายบ้าน และส่งของด่วนขนาดใหญ่ โดยแบ่งบทบาทการใช้งานออกเป็น 3 ประตูหลัก:

1. **ฝั่งลูกค้า (Customer Portal):** เข้าใช้งานผ่าน `http://localhost:3000/`
2. **ฝั่งคนขับ (Driver Portal):** เข้าใช้งานผ่าน `http://localhost:3000/driver`
3. **ฝั่งผู้ดูแลระบบ (Admin Operation):** เข้าใช้งานผ่าน `http://localhost:3000/admin`

---

## 2. คู่มือการใช้งานสำหรับลูกค้า (Customer User Guide)

### 2.1 การเรียกรถขนส่งด่วน (Booking Flow)
1. **เลือกจุดรับและจุดส่งสินค้า:**
   * พิมพ์ที่อยู่ต้นทาง (Pickup Point) และระบุชื่อ/เบอร์โทรผู้ส่ง
   * พิมพ์ที่อยู่ปลายทาง (Dropoff Point) และระบุชื่อ/เบอร์โทรผู้รับ
   * แผนที่ด้านขวาจะคำนวณเส้นทาง ระยะทางรวม (กม.) และเวลาโดยประมาณ
2. **เลือกประเภทรถบรรทุก:**
   * **กระบะทั่วไป (Pickup):** เหมาะสำหรับกล่อง ลัง หรือสินค้าไม่กลัวฝน (สูงสุด 1.5 ตัน)
   * **กระบะตู้ทึบ (Pickup Box):** ป้องกันแดด ฝน ฝุ่นละออง มิดชิด (สูงสุด 1.5 ตัน)
   * **กระบะคอก (Pickup Fence):** ขนของทรงสูงหรือเครื่องจักร (สูงสุด 1.8 ตัน)
   * **จัมโบ้ (Jumbo 4W):** กระบะยาวพิเศษ บรรทุกจุใจ (สูงสุด 2.5 ตัน)
   * **6 ล้อ (6-Wheel Truck):** ขนย้ายบ้าน โรงงาน สินค้าพาเลท (สูงสุด 5.0 ตัน)
3. **เลือกบริการเสริม (Add-on Services):**
   * คนช่วยยกของ (Driver Helper)
   * ทางด่วน (Expressway Service)
4. **ตรวจสอบราคาและยืนยันการจอง:**
   * ตรวจสอบราคาแจกแจงโปร่งใส (ค่าเริ่มต้น + ค่าระยะทาง + ค่าบริการเสริม)
   * กดปุ่ม **"ยืนยันเรียกรถ"** ระบบจะสร้างรหัสงาน (เช่น `JG-2026-10204`) และส่งงานไปยังคนขับรอบพื้นที่
5. **ติดตามงานสด (Live Tracking):**
   * ติดตามตำแหน่ง GPS ของคนขับบนแผนที่สดแบบ Real-time
   * โทรติดต่อคนขับหรือดูความคืบหน้าสถานะ 4 ขั้นตอนจนถึงการส่งมอบสินค้าสำเร็จ

## 3. คู่มือการใช้งานสำหรับคนขับ (Driver User Guide)

### 3.1 การเริ่มต้นและเปิดรับงาน
1. เข้าสู่ระบบผ่านหน้า `http://localhost:3000/driver`
2. สลับปุ่มสวิตช์สถานะเป็น **"ออนไลน์ (พร้อมรับงาน)"**
3. ระบบจะเริ่มจับสัญญาณพิกัด GPS ของคนขับ และค้นหาออเดอร์ใหม่ในรัศมีรอบตัว

### 3.2 การรับงานและการปฏิเสธงาน (Jobs Radar)
1. เมื่อมีลูกค้าเรียกรถในรัศมี จะมีการ์ดงานใหม่เด้งเตือน ระบุ:
   * ระยะทางไปจุดรับ และระยะทางวิ่งส่ง
   * รายได้สุทธิที่คนขับจะได้รับ (Net Payout)
2. คนขับสามารถกด **"รับงานนี้"** เพื่อเริ่มงาน หรือกด **"ปฏิเสธ"** เพื่อรองานถัดไป

### 3.3 การปฏิบัติงานและการอัปเดตสถานะ (Active Job Execution)
* เมื่อคนขับเดินทางถึงจุดรับของ ให้กดปุ่ม **"ถึงจุดรับของแล้ว"**
* เมื่อตรวจเช็กและยกของขึ้นรถเสร็จ ให้กด **"กำลังเดินทางส่ง"**
* เมื่อส่งมอบสินค้าถึงมือผู้รับปลายทาง ให้ถ่ายรูปใบเซ็นรับของหรือสินค้า และกด **"ส่งของสำเร็จ"**
* เงินค่ารอบจะถูกโอนเข้ากระเป๋าเงิน (Driver Wallet) ทันที

## 4. คู่มือการใช้งานสำหรับผู้ดูแลระบบ (Admin User Guide)

### 4.1 การตรวจสอบเอกสารคนขับใหม่ (Driver KYC Verification)
1. เข้าเมนู **"ตรวจ KYC"** ใน Sidebar ซ้าย
2. ตรวจสอบเอกสารสำคัญ 4 ส่วน:
   * ภาพถ่ายบัตรประชาชน และความถูกต้องของเลข 13 หลัก
   * ภาพถ่ายใบขับขี่ และวันหมดอายุ
   * ภาพถ่ายสมุดคู่มือจดทะเบียนรถ และป้ายภาษี
   * ภาพถ่ายหน้าสมุดบัญชีธนาคารสำหรับรับเงินโอน
3. กดปุ่ม **"อนุมัติ (Approve)"** เพื่อให้คนขับเปิดออนไลน์รับงานได้ หรือกด **"ปฏิเสธ (Reject)"** พร้อมระบุเหตุผลเพื่อแจ้งเตือนให้คนขับส่งเอกสารใหม่

### 4.2 การจัดการและติดตามงานสด (Live Dispatch)
* มอนิเตอร์งานที่กำลังเดินทางทั้งหมดในระบบ
* จัดการงานที่มีข้อพิพาทหรือกรณีลูกค้า/คนขับขอยกเลิกฉุกเฉิน

### 4.3 การกำหนดราคา (Pricing Rules)
* เมนู **"ตั้งค่าราคา"** อนุญาตให้แอดมินปรับค่าเริ่มต้น (Base Fare) และอัตราต่อกิโลเมตรของรถแต่ละประเภทตามสภาพเศรษฐกิจและราคาน้ำมัน
